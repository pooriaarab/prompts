# prompts design

## Overview

This repository is reserved for refined prompts used across agent command-line tools.

No prompt exists. This document records current evidence and prevents an invented content contract.

## Typography

## Layout

No filename pattern, frontmatter block, variable syntax, or model-specific folder is defined.

## Elevation & Depth

No visual elevation or content nesting system exists.

Do not define prompt hierarchy, inheritance, composition, or include behavior until tracked content implements it.

## Shapes

No logo, icon, border, container, delimiter, or prompt fence is defined.

Standard Markdown punctuation has no special prompt meaning in the current repository.

## Components

There are no prompt components, templates, examples, variables, tests, renderers, or loaders.

The pull-request review workflow ignores Markdown paths. Prompt documentation therefore needs deliberate human review.

## Do's and Don'ts

Do keep statements tied to tracked files.

Do update this document when the first prompt establishes an actual pattern.

Do state unimplemented behavior as unimplemented.

Don't invent prompt names, roles, variables, frontmatter, examples, or evaluation results.

Don't claim compatibility with a model or agent without testing that prompt there.

Don't add a visual system, web route, or public application to this text collection.
